# 阶段与验收

按顺序做，前一阶段未通过不往后堆功能。后端是最后一步。

## 1. MVP 视角

- 点击画面 Pointer Lock，隐藏系统光标
- 自定义 yaw/pitch（`aim-math` + ref），屏幕中心青柠准星
- 默认开镜：红点 1.25x + MDV 1.33；可切 2 倍
- 验收：同一鼠标滑动，转身幅度接近游戏；FOV 观感接近 1440p 16:9 / 110

## 2. 射击闭环

- 前方 3 个静态球；左键中心 Raycaster
- 命中：球消失、加分、`#DEFF9A` 反馈
- 验收：准星对准必中，打空不计命中

## 3. 手感校准

- 可填 DPI / sens / FOV / 红点|2倍
- 验收：游戏内开镜 180° 或甩到屏幕同一相对位置，垫上距离与训练器一致（允许微调 `yawFactor`）
- **对照游戏暂缓**（条件未就绪）。步骤与记录表：`docs/game-calibration.md`。未填实测表前不要为凑数改公式，也不要开始阶段 4

## 4. 模式

- Flicking：击破刷新；TTK、首发命中率
- Tracking：变速平移（可加急停/短滑铲位移）；Tracking Uptime
- 60 秒一局，局末结算

## 5. 全栈

- Express + Prisma 写 `Session`；个人面板 Recharts 折线
- 验收：刷新后仍能看到最近一周命中率
