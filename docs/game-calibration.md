# 对照游戏（180° 垫上距离）

状态：**暂缓**。训练器侧校准参照已就绪，游戏本体对照暂不能做。有条件后再填实测表，**不要**为了凑数改 MDV / zoom / FOV 公式。

阶段 3 验收：同一套设置下，开镜转 180° 的鼠标垫距离，训练器 ≈ 游戏。允许只微调 `yawFactor`（默认 `0.022`）。

## 对齐什么

- 比的是 **开镜 yaw**（红点、2 倍各测一次），不是腰射 360°。
- HUD「开镜 180° x.x cm」来自 `adsCmPer180`；DPI 只参与厘米展示，不乘进 `movementX`。
- 机主默认：1600 DPI、sens 2、FOV 110、仅 MDV 1.33、镜内放大关。

默认 HUD 预期（改设置后以画面为准）：

| 预设 | 快捷键 | 开镜 180° |
| --- | --- | --- |
| 红点 1.25x | `1` | 约 7.5 cm |
| 2 倍 | `2` | 约 10.8 cm |

腰射 HUD `cm/360 ≈ 13.0` 只作对照，**不是**本轮验收。

## 共同条件（两边必须一样）

- 同一鼠标、同一软件 DPI、Windows 关闭「提高指针精确度」。
- 游戏：Raw Mouse 开、smoothing / 视角加速关（见 `docs/delta-force-research.md`）。
- 训练器：Pointer Lock；Vite 常见地址 `http://localhost:5174/`。
- 自动化浏览器拿不到 Pointer Lock，**不能**代替垫上实测。

## 训练器怎么测

入口：`LookController.tsx`（Pointer Lock + yaw）。后方参照：`TrainingRange.tsx` 后墙青柠十字（`z≈11.92`，眼高）。

1. 点画面锁定指针。点 **重置朝向**（yaw/pitch 归零，面对前方靶）。
2. 选红点或 2 倍。记下 HUD 厘米。
3. 鼠标垫上标起点，水平滑到准星对准后方十字（纯 yaw，少带 pitch）。
4. 尺量起点到终点，与 HUD 比。每镜测 2～3 次取中位。
5. Esc 解锁后再测另一镜，每次先重置朝向。

准星默认略低于球心，不影响 180° yaw。

## 游戏怎么测

1. 进靶场或能看见固定参照物的位置，开镜（先红点，再 2 倍）。
2. 准星对准参照物，垫上标起点，水平转到背面同一相对位置（或明确的 180° 地标）。
3. 尺量距离。设置必须与训练器表单一致后再点训练器「应用」。

## 有偏差时只动 yaw

| 训练器 vs 游戏 | 做法 |
| --- | --- |
| 同样垫上距离，训练器转得**更多**（偏快） | **减小** `yawFactor` |
| 同样垫上距离，训练器转得**更少**（偏慢） | **增大** `yawFactor` |
| 红点准、2 倍不准（或相反） | 先复查两边是否都开镜、zoom 是否搞混；**不要**改 MDV 公式 |

禁止：把 DPI 乘进 `movementX`；改 `mdvScale` / zoom 去凑厘米；用 Drei 默认 Pointer Lock 系数。

公式以 `docs/delta-force-research.md` 为准；单测锁公式，偏差只暴露为 `yawFactor`。
